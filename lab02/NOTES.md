рабочая папка - локальная папка(репозиторий), в которой храниться проект

индекс - подготовленное состояние файлов. ( "подвешенные" измения между add и commit).

commit - фиксация изменений.

Git - система контроля версий, сохраняет выбранные состояния проекта и сведения об их происхождении. ( приложение на локальном компьютере )

GitHub -  сервис,предоставляющий размещение репозиториев и средства совместной работы)
git diff - сравнивает рабочую область с индексом

git diff --staged - сравнивает данные в индексе с последним commit.



ИСПОЛЬЗОВАННЫЕ КОМАНДЫ:

git status - сообщает о состоянии проекта, не изменяя его.

git diff - сравнивает рабочую область с индексом

git diff --staged - сравнивает данные в индексе с последним commit.



ВЕТКИ:



Ветка - Ветка это ответвление от главной ветки, для того, чтобы пробовать что-то "новое", экспериментировать, но при этом не затрагивать главную ветку, на которой находиться рабочая программа.Создание ветки не копирует файлы, появляется только новое имя для существующего commit. 

При новом коммите, если не перейти с помощью switch в другую ветку, коммит сохраниться в той ветке в которой вы находились. ( при создании новой ветки, свитч автоматически переходит в нее =>  следую коммиты будут в ней. При слиянии веток командой marge гит соединяет историю двух разных веток в одну общую. ( если в целевую ветку, куда сливаем ветки, не было добавленно новых коммитов после ответвления, гит просто переносит указатель текущей ветки вперед на вершину сливаемой ветки. Новые коммиты не создаются)
