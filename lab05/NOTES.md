Работа про построчное чтение файла, кодировки и with



строка журнала через пробелы: время, уровень и сообщение. => строка делиться БОЛЕЕ чем на 3 части.



Уровни: 

1. DEBAG
2. INFO
3. WARNING
4. ERROR



встречаются и испорченные строки - БЕЗ уровня или с НЕ ЗНАКОМЫМ уровнем



В logstats.py

1. parse\_event(line) -> dict .  словарь вида {"time","level","message"}/ Негодная строка ValueError
2. count\_levels(lines) -> dict. Считает строки каждого уровня. НЕпригодные под ключом BROKEN
3. top\_errors(lines,n) - n - кол-во самых частых ур-я ERROR \[сообщение, сколько раз]
4. format\_report(counts, errors) - текст отсчёта по готовым подсчётам.

В main.py
1. читает имя файла журнала из первой строки ввода, открывает его ПОСТРОЧНО и печатает 3 числа:
 1. Сколько строк разобрано всего
 2. Сколько из них уровня ERROR
 3. Сколько испорченных
Записывает отсчёт в report.txt
